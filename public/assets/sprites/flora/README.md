# Hướng Dẫn Thêm Đồ Họa Cây Cối & Thảo Dược (Flora)

Thư mục này dùng để chứa file ảnh cho các loài cây lấy gỗ, cây ăn quả và tiên thảo linh dược.

## 1. Danh Sách Tên File Quy Chuẩn
Mỗi loài cây/thảo mộc tương ứng với 1 file ảnh định dạng `.png` (nền trong suốt, khuyến nghị kích thước 16x16, 24x24 hoặc 32x32 px):

| Tên File | Loài Thực Vật | Phẩm Cấp / Đặc Điểm |
| :--- | :--- | :--- |
| `oak_tree.png` | Cây Sồi Cổ Thụ | Cây rừng thường, tán rộng xanh ngát |
| `pine_tree.png` | Tùng Bách Vạn Niên | Cây núi cao, tuyết phủ mùa đông |
| `bamboo.png` | Trúc Rừng / Tử Trúc | Thân mảnh thanh nhã, tao nhã |
| `berry_bush.png` | Bụi Dâu Rừng | Cung cấp quả dại cho cư dân hái ăn |
| `tu_linh_diep.png` | Tụ Linh Diệp | Linh thảo Nhất phẩm, lá phát sáng xanh lam |
| `ngung_huyet_thao.png`| Ngưng Huyết Thảo | Dược liệu luyện đan trị thương, màu đỏ thắm |
| `tay_tuy_chi.png` | Tẩy Tủy Chi | Nấm linh chi linh dược Tam phẩm |
| `cuu_diep_chi_lan.png`| Cửu Diệp Chi Lan | Thần dược Ngũ phẩm, phát hào quang ngũ sắc |

## 2. Cách Kích Hoạt
Kéo thả file ảnh đúng tên vào thư mục này, hệ thống sẽ tự động vẽ ảnh của bạn thay vì vẽ đồ họa Pixel mặc định!
