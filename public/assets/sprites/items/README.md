# Raven Fantasy equipment icons

The item catalog uses selected 32×32 icons copied from the collected packs in `ảnh/`.
The original source packs remain untouched. Item PNG names match their stable gameplay IDs.

| Gameplay item | Source icon | Category |
| --- | --- | --- |
| `raven_dawn_sword` | Weapons `w1.png` | Sword |
| `raven_twin_axe` | Weapons `w9.png` | Twin axes |
| `raven_qi_staff` | Weapons `w14.png` | Spirit staff |
| `raven_traveler_vest` | Armor `a2.png` | Light armor |
| `raven_scale_coat` | Armor `a18.png` | Scale coat |
| `raven_crimson_cuirass` | Armor `a34.png` | Heavy armor |
| `raven_forest_axe` | Tools `f1.png` | Axe |
| `raven_quarry_pick` | Tools `f2.png` | Pickaxe |
| `raven_moon_sickle` | Tools `f3.png` | Sickle |

Armor front layers are generated by `scripts/build-raven-gear-atlases.mjs` from the
matching armor icons. The 32×32 icons are centered in 64×64 frames and repeated over
the existing animation layout so they can be worn by `humanoid_standard` characters.
The frames show a fixed front-facing armor pose during all character animations.

Art source: Clockwork Raven Studios, Raven Fantasy icon packs supplied in `ảnh/`.
