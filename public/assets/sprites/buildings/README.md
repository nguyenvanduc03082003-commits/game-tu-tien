# Hướng Dẫn Thêm Đồ Họa Công Trình Kiến Trúc (Buildings)

Thư mục này dùng để chứa file ảnh cho các công trình kiến trúc của Thôn Làng & Tông Môn.

## 1. Danh Sách Tên File Quy Chuẩn
Mỗi công trình tương ứng với 1 file ảnh định dạng `.png` (khuyến nghị nền trong suốt):

| Tên File | Loại Công Trình | Kích Thước Ô (Tiles) | Kích Thước Pixel Chuẩn |
| :--- | :--- | :--- | :--- |
| `campfire.png` | Lửa Trại Lập Ấp | 2x2 ô | 32x32 px |
| `village_well.png` | Giếng Nước Thôn Làng | 2x2 ô | 32x32 px |
| `thatched_hut.png` | Nhà Tranh / Lều Nghỉ | 2x2 ô | 32x32 px |
| `mortal_farm.png` | Nông Điền / Ruộng Lúa | 3x3 ô | 48x48 px |
| `meditation_cave.png` | Động Phủ Tu Luyện | 3x3 ô | 48x48 px |
| `herb_garden.png` | Dược Viên Trồng Linh Dược| 3x3 ô | 48x48 px |
| `sect_hall.png` | Đại Điện Tông Môn | 4x4 ô | 64x64 px |
| `alchemy_chamber.png` | Luyện Đan Phòng | 3x3 ô | 48x48 px |
| `scripture_pavilion.png`| Tàng Kinh Các | 3x3 ô | 48x48 px |
| `defense_array.png` | Hộ Tông Trận Pháp | 4x4 ô | 64x64 px |

## 2. Cách Kích Hoạt
Chỉ cần kéo thả file ảnh đúng tên vào thư mục này, game sẽ tự động nạp và hiển thị ngay lập tức!
